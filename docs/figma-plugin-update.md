# Figma 插件一键更新

## 首次使用

1. 维护人员单独发送 `品牌Figma插件.command`。
2. 双击运行；如果 macOS 首次阻止运行，请右键点击文件，选择“打开”，再确认一次。
3. 安装完成后，Finder 会自动定位 `manifest.json`。
4. 在 Figma Desktop 中通过“插件 → 开发 → 从 manifest 导入插件”选择该文件。

工具会把插件安装到 `~/BrandStyleFigmaPlugin`。首次导入完成后不要移动该目录，
以后不需要重新导入插件，也不要求用户安装 Git 或 Node.js。

## 日常更新

1. 双击安装目录中的 `品牌Figma插件.command`。
2. 等待“品牌插件更新完成”提示。
3. 关闭当前正在运行的插件窗口。
4. 从 Figma 的开发插件列表重新打开插件。

同一个工具会自动判断当前是首次安装还是日常更新。它会下载最新版插件；如果检测
到本地开发环境，也会自动构建并检查。
为了避免误删工作，开发人员的 Git 目录会在检测到本地修改或分支冲突时安全停止；
普通用户安装目录则直接获取已由维护人员构建好的版本。

## 常见问题

- **提示无法访问 GitHub**：检查网络。当前一键安装方式要求更新仓库可以公开下载。
- **更新后界面没变化**：完全关闭插件窗口，再从 Figma 的开发插件列表重新打开。
- **提示存在本地修改**：不要自行删除文件，把提示和日志发送给维护人员处理。
